# Security

Report suspected vulnerabilities through this repository's GitHub private
vulnerability reporting channel. Do not include credentials, private keys,
deployment endpoints or uncensored capture packets in public issues.

Use the harness only with controlled fixtures and targets you are authorized to
evaluate. The prototype does not authorize releases or establish containment of
a research environment. Review the qualification requirements before live use.

The repository runs publication privacy checks, redacted secret scans and locked
dependency CVE audits. Generated signing keys and captured evidence are excluded
from source control. Provide CI trust anchors and deployment credentials through
separate protected configuration.
